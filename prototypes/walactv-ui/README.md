# Propuestas visuales de WalacTV

Prototipo HTML autónomo para comparar tres direcciones antes de modificar la aplicación Angular.

- **Butaca:** cálida y editorial, con navegación lateral estable.
- **Guía:** compacta, con navegación superior y más densidad en el catálogo.
- **Proyección:** navegación reducida e interfaz más amplia para el contenido y el reproductor.

Abre `index.html` o sirve esta carpeta localmente. Usa los selectores superiores para cambiar dirección, pantalla y tamaño. La vista «Iconos y componentes» reúne navegación, botones, estados, tipografía, colores y favicon.

Todo el catálogo, las cuentas, las métricas y los estados son de muestra. No se conecta a la API, IPTV ni servicios externos. Los carteles son ilustraciones CSS para comparar proporciones, no arte ni metadata del catálogo.

## Referencias de interacción

- [Nuvio TV](https://nuvio-tv.com/), amplitud de navegación para pantallas de salón y filas organizadas.
- [Stremio Web](https://github.com/Stremio/stremio-web), navegación reconocible y prioridad visual del reproductor.

La propuesta conserva la identidad de WalacTV; no reutiliza sus marcas, recursos o iconos.
